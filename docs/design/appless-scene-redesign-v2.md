# Appless 场景界面重设计 V2

交互设计预览：[`appless-scene-redesign-v2.html`](./appless-scene-redesign-v2.html)

## 设计边界

以下区域保持现状，不在本轮重设计范围内：

- 主页面的时间、日期、问候语与整体布局
- `home_light_aurora_background` 背景图
- 顶部 Appless 标识、心上事、历史、重置、画像与设置入口
- 底部输入对话框及其语音、发送交互

允许调整的区域：

- 出行结果内容区
- 打车结果与订单状态内容区
- 点餐结果内容区
- 基础对话内容区
- 思考过程与执行轨迹内容区

## 统一视觉方向

- 所有场景继续使用主页面的暖白、低饱和、轻玻璃视觉语言。
- 场景内容直接叠加在现有背景之上，不再用大幅海报遮挡背景。
- 主文字使用深棕色，主要操作使用陶土色；绿色、蓝色仅表达交通类型和状态。
- 卡片圆角、间距、按钮高度和展开方式保持一致。
- 信息层级遵循“任务摘要 → 筛选或状态 → 结果 → 次级操作”。

## 功能保留清单

### 出行

- 全部、高铁、飞机切换
- 最快、有票、更多筛选
- 换日期、重新查询
- 结果数量与展开/收起
- 行程详情、价格、余票和来源
- 日历冲突提示与加入日历
- 12306 购票、支付宝购票、携程订票
- 未开售车次的开售抢票
- 固定到桌面

### 打车

- 路线、任务阶段、车型数和接驾状态
- 车型选择与实时价格
- 确认叫车
- 打开滴滴、打开高德
- 订单号、司机、预计接驾时间
- 司机地图与全屏地图
- 刷新司机位置、重新查询、换车型、取消订单

### 点餐

- 当前地址、地址搜索与地图选点
- 重新定位、保存当前位置、使用或删除常用地址
- 全部、精选、1 公里内、来源、咖啡、深夜、聚餐、轻食筛选
- 价格、评分、营业状态和排序筛选
- 清除筛选、换关键词、展示更多
- 商家展开/收起与完整详情
- 导航去、拨打电话、固定到桌面

### 基础对话

- 最新用户消息与助手回答
- 上下文数量和折叠/展开
- 不新增业务动作，不改变底部输入方式

### 思考过程

- 用户请求摘要
- 当前执行状态
- 执行轨迹及完成、进行中、等待状态
- 本次上下文折叠/展开

## 实现约束

- 沿用现有 A2UI 数据路径和动作 ID，不改变业务协议。
- 仅调整场景渲染器的结构与样式，不改 `HomePage` 和背景资源。
- 加载、空结果、错误、确认和取消状态必须继续由现有数据驱动。
