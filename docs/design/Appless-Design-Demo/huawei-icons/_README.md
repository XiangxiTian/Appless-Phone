# 华为 HarmonyOS Symbol

本文件夹平铺保存了 404 个不重复的 HarmonyOS 官方 Symbol SVG，方便直接在 Finder 中预览和按英文名称搜索。

- 格式：SVG
- 画布：24 × 24
- 样式：常规体、单色
- 背景：透明
- 默认颜色：`#191919`
- 名称索引：`_INDEX.csv`
- 官方来源：https://developer.huawei.com/consumer/cn/design/harmonyos-symbol/HarmonyOS

华为官网当前分类清单共有 433 条记录，其中部分 Symbol 同时出现在多个分类；本文件夹按英文名称合并后共有 404 个独立图标。分类关系均保留在 `_INDEX.csv` 中。
