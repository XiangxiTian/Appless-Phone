## 验收结果

1. “在 App 内继续预订”会打开 App 内 RollingGo 安全页面，且酒店与已选酒店一致。
2. 关闭供应商页面后恢复到“核验酒店订单”，不会把网页打开或返回误报成预订成功。
3. “核验供应商订单”进入本地受控适配器；RollingGo 当前没有可用订单查询接口时，明确提示用户手动确认，不生成虚假订单号或支付状态。
4. 用户选择“本次没有完成”后，页面保存取消状态，并提供“重新打开预订页”和“再次核验订单”。
5. `travel.hotel.booking.open` 使用出差流程专用动作，避免与普通酒店页的 `hotel.booking.open` 注册动作冲突。
