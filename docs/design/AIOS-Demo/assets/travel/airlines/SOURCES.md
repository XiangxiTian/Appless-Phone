# Airline logo sources

Local raster assets used by the flight-search prototype. The UI does not load remote images at runtime.

- Shenzhen Airlines: <https://www.vhv.rs/viewpic/hwwmhJo_shenzhen-airlines-logo-shenzhen-airlines-hd-png-download/>; cropped to the official phoenix symbol for the compact carrier row.
- China Eastern Airlines: <https://companieslogo.com/china-eastern-airlines/logo/>; transparent symbol PNG.
- China Southern Airlines: <https://www.pngitem.com/middle/ToRRhwh_china-southern-airlines-logo-clipart-png-download-logo/>; transparent kapok symbol PNG.
- Juneyao Air: <https://www.iguopin.com/company?id=10685329757032349>; cropped to the official circular emblem for the compact carrier row.
- Spring Airlines: <https://companieslogo.com/de/spring-airlines/logo/>; transparent symbol PNG. The same mark is also published by Spring Airlines and Wikimedia Commons.
