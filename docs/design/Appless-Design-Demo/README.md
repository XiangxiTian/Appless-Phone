# Appless 交互原型

## 直接体验

1. 解压整个压缩包。
2. 双击 `index.html`。
3. 使用页面顶部的胶囊按钮切换场景，在手机画布内点击、滚动或左右滑动。

这个原型不需要安装应用、Node.js、npm 或任何依赖，也不需要启动本地服务。页面和所需素材都已包含在压缩包内，可以离线打开。

## 注意事项

- 请保留 `index.html` 和 `assets/` 的相对位置，不要只单独发送 HTML 文件。
- 建议使用最新版 Chrome、Edge 或 Safari。
- 手机画布采用固定 432 × 960 设计坐标，会随浏览器窗口等比缩放，内部元素不会重新排版或变形。
- 这是视觉与交互关系原型，使用固定演示内容，不连接模型、支付、地图或其他在线服务。

素材来源与 HarmonyOS Symbol 映射记录在 `assets/SOURCES.md`。
